# REPL

Основная функция программы:

```python
def repl(node, vfs_name='VFS'):
```

Функция запускает бесконечный цикл обработки пользовательских команд.

При запуске пользователю отображается приглашение:

```text
VFS:/>
```

Имя VFS передаётся вторым аргументом функции:

```python
repl(root, 'VFS')
```

Таким образом, приглашение содержит имя виртуальной файловой системы.

---

# Раскрытие переменных окружения

Для раскрытия переменных окружения используется функция:

```python
os.path.expandvars(command_line)
```


Команда:

```text
echo $HOME
```

преобразуется примерно в:

```text
C:\Users\*имя пользователя*\...
```

Таким образом, REPL использует реальные переменные окружения операционной системы.

---

# Разбор команд

После раскрытия переменных окружения строка разделяется на отдельные элементы:

```python
args = command_line.split()
```

Первый элемент считается названием команды:

```python
command = args[0]
```

Остальные элементы считаются аргументами:

```python
arguments = args[1:]
```

Например, для команды:

```text
cd /home
```

получается:

```text
command = "cd"
arguments = ["/home"]
```

# Реализованные команды

На первом этапе реализованы следующие команды:

| Команда | Аргументы | Назначение |
|---|---|---|
| `ls` | нет | Заглушка команды просмотра содержимого |
| `cd` | 1 | Заглушка команды перехода в каталог |
| `echo` | любое количество | Вывод переданных аргументов |
| `exit` | нет | Завершение работы VFS |

---

## Команда `ls`

Команда `ls` является заглушкой.

При корректном вызове:

```text
VFS:/> ls
ls
```

Команда пока не выполняет реальный просмотр содержимого VFS.

Передача аргументов вызывает ошибку:

```text
VFS:/> ls test
Ошибка: ls не принимает аргументы
```

Таким образом, количество аргументов проверяется перед выполнением команды.

---

## Команда `cd`

Команда `cd` является заглушкой перехода в каталог.

Она требует **ровно один аргумент**.

Корректный вызов:

```text
VFS:/> cd /home
cd /home
```

При отсутствии аргумента:

```text
VFS:/> cd
Ошибка: cd требует один аргумент
```

При передаче нескольких аргументов:

```text
VFS:/> cd /home /tmp
Ошибка: cd требует ровно один аргумент
```

На первом этапе команда не выполняет фактический переход между каталогами.

---

## Команда `echo`

Команда `echo` выводит переданные ей аргументы:

```text
VFS:/> echo Hello
Hello
```

Несколько аргументов:

```text
VFS:/> echo Hello World
Hello World
```

---

## Команда `exit`

Команда `exit` завершает работу REPL.

Корректный вызов:

```text
VFS:/> exit
Выход из VFS...
```

После выполнения команды программа завершает цикл и прекращает работу.

Команда `exit` не принимает аргументы:

```text
VFS:/> exit test
Ошибка: exit не принимает аргументы
```

После такой ошибки REPL продолжает работу.

---

# Обработка неизвестных команд

Если пользователь вводит команду, которая не поддерживается программой, выводится сообщение об ошибке:

```text
VFS:/> mkdir
Ошибка: неизвестная команда mkdir
```

После ошибки программа продолжает ожидать следующую команду.

Например:

```text
VFS:/> test
Ошибка: неизвестная команда test

VFS:/> ls
ls
```

Это позволяет продолжать работу REPL после возникновения ошибки.

# Этап 2. Конфигурация

## Цель второго этапа

Сделать эмулятор настраиваемым, то есть поддержать ввод параметров
пользователя в приложение. Организовать для этого этапа отладочный вывод всех
заданных параметров при запуске эмулятора.
Требования:
1. Параметры командной строки:
– Путь к физическому расположению VFS.
– Путь к стартовому скрипту.
2. Стартовый скрипт для выполнения команд эмулятора: выполняет команды
последовательно, ошибочные строки пропускает. При выполнении скрипта
на экране отображается как ввод, так и вывод, имитируя диалог с
пользователем.
3. Создать несколько скриптов реальной ОС, в которой выполняется эмулятор.
Включить в каждый скрипт вызовы эмулятора для тестирования всех
поддерживаемых параметров командной строки.

# Параметры командной строки

Для обработки параметров командной строки используется стандартный модуль Python:

```python
import argparse
```

Разбор параметров выполняется функцией:

```python
def parse_arguments():
```

В программе поддерживаются два параметра:

| Параметр | Значение по умолчанию | Назначение |
|---|---|---|
| `--vfs-path` | `./vfs` | Путь к физическому расположению VFS |
| `--script` | `./startup.txt` | Путь к стартовому скрипту |

---

## Параметр `--vfs-path`

Параметр:

```text
--vfs-path
```

задаёт путь к физическому каталогу, который используется как расположение VFS.

Например:

```text
--vfs-path ./vfs
```

В этом случае каталог VFS находится в папке:

```text
./vfs
```

---

## Параметр `--script`

Параметр:

```text
--script
```

задаёт путь к стартовому скрипту.

Например:

```text
--script ./startup.txt
```

В данном случае программа будет выполнять команды из файла:

```text
startup.txt
```

---

# Значения параметров по умолчанию

Параметры командной строки имеют значения по умолчанию:

```python
parser.add_argument(
    "--vfs-path",
    default="./vfs",
    help="Путь к физическому расположению VFS"
)

parser.add_argument(
    "--script",
    default="./startup.txt",
    help="Путь к стартовому скрипту"
)
```

Также параметры можно указать явно:

```text
python emulator.py --vfs-path ./vfs --script ./startup.txt
```

---

# Обработка путей

Перед использованием пути к VFS и стартовому скрипту программа раскрывает переменные окружения:

```python
vfs_path = os.path.expandvars(args.vfs_path)
script_path = os.path.expandvars(args.script)
```

После этого пути преобразуются в абсолютные:

```python
vfs_path = os.path.abspath(vfs_path)
script_path = os.path.abspath(script_path)
```

Например, относительный путь:

```text
./vfs
```

может быть преобразован в:

```text
C:\Users\*имя пользователя*\*папка проекта*\vfs
```


---

# Проверка и создание VFS

Перед запуском стартового скрипта программа проверяет существование каталога VFS:

```python
if not os.path.exists(vfs_path):
    print(f"Предупреждение: VFS не существует: {vfs_path}")
    print("Будет создан VFS.")

    os.makedirs(vfs_path)
```

Если указанный каталог отсутствует, он создаётся автоматически.

Если указанный путь существует, но не является каталогом, программа выводит ошибку:

```python
if not os.path.isdir(vfs_path):
    print(f"Ошибка: путь VFS не является каталогом: {vfs_path}")
    return
```

# Стартовый скрипт

Для автоматического выполнения команд используется файл:

```text
startup.txt
```

Пример содержимого:

```text
echo запуск эмулятора
ls
cd test
echo открыт startup.txt
unknown
ls
```

Команды из файла выполняются последовательно сверху вниз.

---

# Выполнение стартового скрипта

Для выполнения стартового скрипта используется функция:

```python
def execute_script(script_path):
```

Файл открывается следующим образом:

```python
with open(script_path, "r", encoding="utf-8") as script:
```

Затем программа последовательно читает все строки:

```python
for line_number, line in enumerate(script, start=1):
```

Пустые строки пропускаются:

```python
if not command_line:
    continue
```

Каждая непустая команда перед выполнением отображается на экране:

```python
print(f"> {command_line}")
```

После этого команда передаётся функции:

```python
execute_command(command_line)
```

Таким образом, выполнение стартового скрипта имитирует диалог с пользователем.

# Обработка ошибок в стартовом скрипте

Ошибочная команда не останавливает выполнение всего стартового скрипта.

Если файл содержит:

```text
echo Начало
unknown

echo Конец
```

то программа выполнит все команды:

```text
> echo Начало
Начало

> unknown
Ошибка: неизвестная команда unknown

> ls
ls

> echo Конец
Конец
```

После выполнения всех команд программа выводит:

```text

```

После этого запускается интерактивный REPL:

```text
vfs:/>
```

Пользователь может продолжить работу с эмулятором вручную.

# Обработка отсутствующего стартового скрипта

```text

```

Ошибка не вызывает аварийное завершение программы.

После обработки ошибки программа продолжает работу и переходит в интерактивный REPL.

# Скрипт реальной операционной системы

Для автоматического запуска эмулятора создан скрипт реальной операционной системы.

Для Windows используется файл:

```text
test.bat
```

Его содержимое:

```bat
@echo off

python emulator.py --vfs-path ./vfs --script ./startup.txt

pause
```

Данный скрипт запускает программу эмулятора и передаёт ей оба поддерживаемых параметра:

```text
--vfs-path ./vfs
--script ./startup.txt
```

После завершения работы программы команда:

```text
pause
```

оставляет окно открытым для просмотра результата.
