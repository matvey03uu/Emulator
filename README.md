# Практическая работа №1

## Цели первого этапа

1. Приложение должно быть реализовано в форме консольного интерфейса
(CLI).
2. Приглашение к вводу должно содержать имя VFS.
3. Реализовать парсер, который поддерживает раскрытие переменных
окружения реальной ОС (например, $HOME).
4. Сообщить об ошибке выполнения команд (неизвестная команда, неверные
аргументы).
5. Реализовать команды-заглушки, которые выводят свое имя и аргументы: ls,
cd.
6. Реализовать команду exit.
7. Продемонстрировать работу прототипа в интерактивном режиме.

---

## Используемые технологии

- Модуль `os` для работы с переменными окружения

# REPL

Основная функция программы:

```python
def repl(node, vfs_name='VFS'):
```

Функция запускает бесконечный цикл обработки пользовательских команд.

При запуске пользователю отображается приглашение:

```text
VFS:/>
```

Имя VFS передаётся вторым аргументом функции:

```python
repl(root, 'VFS')
```

Таким образом, приглашение содержит имя виртуальной файловой системы.

---

# Раскрытие переменных окружения

Для раскрытия переменных окружения используется функция:

```python
os.path.expandvars(command_line)
```

Она заменяет переменные окружения операционной системы их текущими значениями.

В Windows можно использовать:

```text
%USERPROFILE%
```

После раскрытия переменной команда:

```text
cd %USERPROFILE%
```

преобразуется примерно в:

```text
cd C:\Users\*имя пользователя*
```

Таким образом, REPL использует реальные переменные окружения операционной системы.

---

# Разбор команд

После раскрытия переменных окружения строка разделяется на отдельные элементы:

```python
args = command_line.split()
```

Первый элемент считается названием команды:

```python
command = args[0]
```

Остальные элементы считаются аргументами:

```python
arguments = args[1:]
```

Например, для команды:

```text
cd /home
```

получается:

```text
command = "cd"
arguments = ["/home"]
```

# Реализованные команды

На первом этапе реализованы следующие команды:

| Команда | Аргументы | Назначение |
|---|---|---|
| `ls` | нет | Заглушка команды просмотра содержимого |
| `cd` | 1 | Заглушка команды перехода в каталог |
| `echo` | любое количество | Вывод переданных аргументов |
| `exit` | нет | Завершение работы VFS |

---

## Команда `ls`

Команда `ls` является заглушкой.

При корректном вызове:

```text
VFS:/> ls
ls
```

Команда пока не выполняет реальный просмотр содержимого VFS.

Передача аргументов вызывает ошибку:

```text
VFS:/> ls test
Ошибка: ls не принимает аргументы
```

Таким образом, количество аргументов проверяется перед выполнением команды.

---

## Команда `cd`

Команда `cd` является заглушкой перехода в каталог.

Она требует **ровно один аргумент**.

Корректный вызов:

```text
VFS:/> cd /home
cd /home
```

При отсутствии аргумента:

```text
VFS:/> cd
Ошибка: cd требует один аргумент
```

При передаче нескольких аргументов:

```text
VFS:/> cd /home /tmp
Ошибка: cd требует ровно один аргумент
```

На первом этапе команда не выполняет фактический переход между каталогами.

---

## Команда `echo`

Команда `echo` выводит переданные ей аргументы:

```text
VFS:/> echo Hello
Hello
```

Несколько аргументов:

```text
VFS:/> echo Hello World
Hello World
```

---

## Команда `exit`

Команда `exit` завершает работу REPL.

Корректный вызов:

```text
VFS:/> exit
Выход из VFS...
```

После выполнения команды программа завершает цикл и прекращает работу.

Команда `exit` не принимает аргументы:

```text
VFS:/> exit test
Ошибка: exit не принимает аргументы
```

После такой ошибки REPL продолжает работу.

---

# Обработка неизвестных команд

Если пользователь вводит команду, которая не поддерживается программой, выводится сообщение об ошибке:

```text
VFS:/> mkdir
Ошибка: неизвестная команда mkdir
```

После ошибки программа продолжает ожидать следующую команду.

Например:

```text
VFS:/> test
Ошибка: неизвестная команда test

VFS:/> ls
ls
```

Это позволяет продолжать работу REPL после возникновения ошибки.
